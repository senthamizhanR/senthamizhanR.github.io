# senthamizhanR.github.io

Personal academic site of R. Senthamizhan (nonlinear dynamics, swarmalators).

- `index.html` - the whole site: static HTML/CSS with a little vanilla JS (theme toggle, publication filter, scroll reveal). No build step.
- `assets/photo.jpg` - portrait used in the top bar, hero and link previews.
- `fw_1d_swarmalator.html` - interactive frequency-weighted swarmalator visualizer.
- `cv-site-source-1.zip` - source of the previous React/Vite version, kept for reference.

The CV button links to `R_Senthamizhan_CV.pdf` in the senthamizhanR/CV repo; update it there.
