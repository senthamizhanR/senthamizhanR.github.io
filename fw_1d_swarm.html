Governing equations

Each swarmalator \(i\) has position \(x_i\in[-\pi,\pi]\) and phase \(\theta_i\in[-\pi,\pi]\):

\[ \dot{x}_i = v_i + \frac{J}{N}\sum_{j}\sin(x_j-x_i)\,|\omega_i|\cos(\theta_j-\theta_i), \] \[ \dot{\theta}_i = \omega_i + \frac{K}{N}\sum_{j}\cos(x_j-x_i)\,|\omega_i|\sin(\theta_j-\theta_i). \]

\(J\) sets spatial attraction and \(K\) sets phase synchronization; the factor \(|\omega_i|\) makes each agent's influence frequency weighted.

Order parameters

The coupled space–phase coherence channels are

\[ W^{\pm}=S_{\pm}e^{i\psi_{\pm}}=\frac{1}{N}\sum_{j}e^{i(x_j\pm\theta_j)}. \]

Small \(S_\pm\) marks the asynchronous cloud; one dominant channel marks the phase-wave strip; both large indicates the bi-strip mixed state.

Exact mean-field reduction (used here)

Product-to-sum identities collapse the \(O(N^2)\) pairwise sums into \(O(N)\) terms expressed through \(W^{\pm}\), so the loop below is exact, not approximate:

\[ F_i^+ = S_+\sin(\psi_+ - x_i - \theta_i), \qquad F_i^- = S_-\sin(\psi_- - x_i + \theta_i). \] \[ \dot{x}_i = v_i + \tfrac{1}{2}J|\omega_i|\left(F_i^+ + F_i^-\right), \qquad \dot{\theta}_i = \omega_i + \tfrac{1}{2}K|\omega_i|\left(F_i^+ - F_i^-\right). \]

This keeps the same interaction law as the pairwise model while staying fast enough for real-time rendering at large \(N\).

Integration

Explicit Euler with wrapping to \([-\pi,\pi]\):

\[ x_i(t+\Delta t)=\mathrm{wrap}\!\left[x_i + \Delta t\,\dot{x}_i\right]. \]

Default \(\Delta t = 0.015\) with four steps per frame. Reduce \(\Delta t\) if the portrait becomes noisy at strong coupling.

Ensemble & presets

  • \(x_i,\theta_i\) uniform on \([-\pi,\pi]\).
  • \(v_i,\omega_i\) drawn from centered Cauchy \((\gamma=1)\), clipped to \(|\cdot|\le 8\).
  • Presets: AS \((12,-8)\), PW \((12,0.5)\), BM \((12,10)\).
